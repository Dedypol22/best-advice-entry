## The Best Advice I Ever Got

> My father said, 'When everyone at the table is laughing at someone who isn't there, leave the table.'

This line wins because it is a real voice recalling a real moment: a father, a crowded table, laughter aimed at someone absent. The advice is specific and earned — not a slogan, but a rule about loyalty and the company you keep that stays true far beyond that one dinner. Every word works, it reads in a single breath, and it ends on an action the reader can carry out the next time they sit at such a table.

## Run it

```sh
python3 main.py
```

The program writes the single sentence to `entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with no trailing newline. The line is **101 characters** long.
